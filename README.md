### Programa de Lista de Tarefas.
Isto é um exercício de criar um programa de lista de tarefas.
Esse desafio é mais para que eu aprenda a mexer com o CustomTkinter em específico.

Agora falando sobre o programa em si, Ele é um programa bem simples de lista de tarefas, onde o usuário pode organizar os deveres.
Seque as funcionalidades que planejo para o programa:
* Adicionar tarefas a lista.
* Contador de tarefas, mostrando quantas tarefas faltam para terminar em relação ao total.
* Salvamento automático das sua tarefas em arquivos .json.
* Visualização das suas tarefas atrás de uma lista com blocos dinâmicos.
* Caixa de seleção em cada tarefa.
* Botão "X" para apagar as tarefas para dar lugar a novas.
